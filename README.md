🛍️ Korsar - E-commerce Fashion Website

Korsar est une plateforme e-commerce moderne dédiée à une marque de vêtements.
Le projet inclut un site vitrine ainsi qu’un dashboard admin pour la gestion des produits et commandes.

🌐 Live Demo : https://korsar.vercel.app

🚀 Tech Stack
⚡ Next.js
🎨 Tailwind CSS
📊 Recharts (dashboard analytics)
🧠 LocalStorage (simulation backend - en cours de migration)
🧩 Lucide Icons
🚀 Vercel (déploiement)
✨ Features
🛒 Site Client
Landing page moderne avec hero animé
Présentation de la marque Korsar
Catalogue produits
Section services
Formulaire de contact
Interface responsive (mobile / desktop)
📊 Admin Dashboard
Système d’authentification admin
Gestion des produits
Gestion des commandes
Statistiques (revenus, commandes, produits)
Graphiques interactifs avec Recharts
Interface type SaaS moderne
⚙️ Backend (actuel)

Actuellement, les données sont gérées via LocalStorage (côté client) pour simuler un backend.

👉 Une migration vers Supabase (PostgreSQL + Auth) est prévue pour rendre l’application plus scalable et professionnelle.

📦 Installation
# cloner le projet
git clone https://github.com/ton-username/korsar.git
