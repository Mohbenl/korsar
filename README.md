# 🛍️ Korsar - E-commerce Fashion Website

Korsar est une plateforme e-commerce moderne dédiée à une marque de vêtements.  
Le projet inclut un site vitrine + un système de gestion admin pour gérer les produits et les commandes.

🌐 Live Demo : https://korsar.vercel.app

---

## 🚀 Tech Stack

- ⚡ Next.js (pour l’admin dashboard)
- 🎨 Tailwind CSS
- 📊 Recharts (analytics dashboard)
- 🧠 LocalStorage (simulation backend)
- 🧩 Lucide Icons
- 🚀 Déploiement : Vercel

---

## ✨ Features

### 🛒 Site Client
- Page d’accueil moderne avec hero animé
- Présentation de la marque Korsar
- Catalogue produits
- Section services
- Formulaire de contact
- UI responsive (mobile / desktop)

### 📊 Admin Dashboard
- Auth admin
- Gestion des produits
- Gestion des commandes
- Statistiques (revenu, commandes, produits)
- Graphiques interactifs (Recharts)
- Interface type SaaS moderne
